# CD4520B — Harris Semiconductor / Texas Instruments

## Description

The CD4520B is a CMOS dual binary up-counter. Each counter stage has an independent clock input, enable input, reset input, and four buffered outputs (Q1-Q4). The counters increment on the rising edge of the clock input when enable is low, or on the falling edge of the enable input when clock is high. The reset input asynchronously clears all outputs to zero when driven high.

## Features

- Dual 4-bit binary up-counter
- Wide supply voltage range: 3 V to 18 V
- Independent clock, enable, and reset for each counter
- Four buffered outputs per counter
- Asynchronous reset
- Cascadable for higher bit counts
- Low quiescent power dissipation
- 5 V, 10 V, and 15 V parametric ratings

## Truth Tables

### Counter Operation

| RESET | CLOCK | ENABLE | Action |
|-------|-------|--------|--------|
| 1 | X | X | Q1-Q4 = 0 (asynchronous reset) |
| 0 | Rising | 0 | Count increments |
| 0 | X | Falling | Count increments (when CLOCK = 1) |
| 0 | 0 or Falling | 1 | No change |
