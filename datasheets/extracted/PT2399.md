# PT2399 — Princeton Technology Corp.

## Description

PT2399 is an echo audio processor IC utilizing CMOS technology equipped with ADC and DAC, high sampling frequency, and an internal memory of 44K. Digital processing is used to generate the delay time. It also features an internal VCO circuit in the system clock, making the frequency easily adjustable. PT2399 has very low distortion (THD < 0.5%) and very low noise (No < -90 dBV), producing high quality audio output. The pin assignments and application circuit are optimized for easy PCB layout and cost saving.

## Features

- CMOS technology
- Minimal external components
- Auto reset function
- Low noise: No < -90 dBV typical
- Low distortion: THD < 0.5% typical
- External adjustable VCO
- Available in 16-pin DIP or SO package

## Typical Application Circuits

**Echo Application:** Uses external resistor R (10 kOhm recommended) connected to VCO pin (pin 6). When R increases, the delay time range also increases. Supply voltage: +5 V.

**Surround/Delay Application:** Similar circuit with modified filter components for surround sound effect.
