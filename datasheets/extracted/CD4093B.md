# CD4093B -- Texas Instruments

## Description

The CD4093B consists of four Schmitt-trigger circuits. Each circuit functions as a two-input NAND gate with Schmitt-trigger action on both inputs. The gate switches at different points for positive- and negative-going signals. The difference between the positive voltage (VP) and the negative voltage (VN) is defined as hysteresis voltage (VH). The device is a high-voltage type (20-Volt Rating).

## Features

- Schmitt-trigger action on each input with no external components
- Hysteresis voltage typically 0.9 V at VDD = 5 V and 2.3 V at VDD = 10 V
- Noise immunity greater than 50%
- No limit on input rise and fall times
- Standardized, symmetrical output characteristics
- 100% tested for quiescent current at 20 V
- Maximum input current of 1 uA at 18 V over full package-temperature range; 100 nA at 18 V and 25 C
- 5-V, 10-V, and 15-V parametric ratings
- Meets all requirements of JEDEC Tentative Standard No. 13B

## Typical Application Circuits

- **Wave Shaper**: Single gate used to square up slow signals. Frequency range of wave shape is from DC to 1 MHz.
- **Monostable Multivibrator**: Uses 1/3 CD4007A and 1/4 CD4093B with RC timing. td = RC * 3n, 50 kohm <= R <= 1 Mohm, 100 pF <= C <= 1 uF. For the range of R and C given: 5 us < td < 1 s.
- **Astable Multivibrator**: Uses 1/4 CD4093B with RC timing. td = RC * ln((VDD-VN)/(VDD-VP)), 50 kohm <= R <= 1 Mohm, 100 pF <= C <= 1 uF.
- **Contact Debouncer**: VDD with R = 120 kohm, C = 0.001 uF, connected to switch or relay contact through CD4093B gate.
