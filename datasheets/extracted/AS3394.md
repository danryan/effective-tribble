# AS3394E — Alfa RPAR

## Description

The AS3394E is an analog synthesizer voice IC that integrates a complete synthesizer voice channel on a single chip. It contains a voltage-controlled oscillator (VCO) with sawtooth, triangle, and variable-width pulse waveforms, a sub-oscillator, a voltage-controlled filter (VCF), and a voltage-controlled amplifier (VCA). The device is designed for use in polyphonic and monophonic analog synthesizers.

## Features

- Complete synthesizer voice on a single chip
- VCO with sawtooth, triangle, and variable-width pulse waveforms
- Sub-oscillator output (one octave below VCO)
- 4-pole low-pass voltage-controlled filter (VCF)
- Voltage-controlled amplifier (VCA)
- Waveform select via voltage thresholds
- Wide frequency range VCO
- Low power consumption
- 24-pin DIP package
