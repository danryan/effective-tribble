# LM741 — Texas Instruments

## Description

The LM741 series are general-purpose operational amplifiers featuring improved performance over industry standards like the LM709. They are direct, plug-in replacements for the 709C, LM201, MC1439, and 748 in most applications. The amplifiers offer overload protection on the input and output, no latch-up when the common-mode range is exceeded, and freedom from oscillations. The LM741C is identical to the LM741/LM741A except that performance is ensured over 0°C to +70°C instead of -55°C to +125°C.

## Features

- Overload protection on the input and output
- No latch-up when the common-mode range is exceeded
- Freedom from oscillations
- Short-circuit protection

## Typical Application Circuits

### Noninverting Amplifier

Connect signal to noninverting input (pin 3). Feedback resistor R2 from output (pin 6) to inverting input (pin 2). Input resistor R1 from inverting input to ground. Gain = 1 + (R2/R1). With R1 = R2 = 4.7 kohm, gain = 2. Bypass VCC with 0.1 uF capacitors.
