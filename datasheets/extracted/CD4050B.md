# CD4050B — Texas Instruments

## Description

The CD4050B is a noninverting hex buffer featuring logic-level conversion using only one supply voltage (VCC). The input-signal high level (VIH) can exceed the VCC supply voltage when used for logic-level conversions. The device is intended for use as a CMOS to DTL or TTL converter and can drive directly two DTL or TTL loads (VCC = 5V, VOL <= 0.4V, IOL >= 3.3 mA).

## Features

- CD4050B noninverting (CD4049UB inverting version also available)
- High sink current for driving 2 TTL loads
- High-to-low level logic conversion
- 100% tested for quiescent current at 20V
- Maximum input current of 1 uA at 18V over full package temperature range; 100 nA at 18V and 25°C
- 5V, 10V, and 15V parametric ratings

## Typical Application Circuits

The CD4050B can be used as a level-shifting buffer to convert higher-voltage CMOS logic to lower-voltage CMOS, DTL, or TTL levels. A typical application drives an LED from a logic signal through a current-limiting resistor, with VCC set to the desired output logic level. A 0.1 uF bypass capacitor is recommended on VCC.
