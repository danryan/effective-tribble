# CD4022B — Texas Instruments

## Description

The CD4022B is a 4-stage Johnson counter with 8 decoded outputs. It is a CMOS octal counter/divider. Inputs include a CLOCK, a RESET, and a CLOCK INHIBIT signal. Schmitt trigger action in the CLOCK input circuit provides pulse shaping that allows unlimited clock input pulse rise and fall times. The counter advances one count at the positive clock signal transition if the CLOCK INHIBIT signal is low. A high RESET signal clears the counter to its zero count. A CARRY-OUT signal completes one cycle every 8 clock input cycles and is used to ripple-clock the succeeding device in a multi-device counting chain.

## Features

- Fully static operation
- Medium-speed operation: 10 MHz (typ.) at VDD = 10 V
- Standardized, symmetrical output characteristics
- 100% tested for quiescent current at 20 V
- 5 V, 10 V, and 15 V parametric ratings
- 8 decoded outputs
- Carry out for cascading
- Binary counter/decoder
- Divide-by-N counting

## Typical Application Circuits

### Divide-by-N Counter

Connect COUT (carry out) to RESET through external logic (e.g., two NOR gates from CD4001B) to create a divide-by-N counter where N ranges from 2 to 10. The Nth decoded output triggers the S-R flip flop reset. If the Nth output is >= 6 (for CD4022B), the COUT line goes high to clock the next stage.

### Cascading Counters

Connect the CARRY OUT of the first CD4022B to the CLOCK input of the next stage. Each stage divides by 8. Multiple stages can be cascaded for higher count ranges.
