# CD4047B — Harris Semiconductor / Texas Instruments

## Description

The CD4047B is a CMOS low-power monostable/astable multivibrator. It requires an external timing resistor (R) and timing capacitor (C) to determine the output pulse width in monostable mode or the output frequency in astable mode. The astable frequency is f = 1/(4.40 RC) and the monostable pulse width is t = 2.48 RC. The device features retriggering capability, external reset, and complementary outputs.

## Features

- Low-power monostable/astable multivibrator
- Wide supply voltage range: 3 V to 18 V
- Astable operation with 50% duty cycle
- Monostable operation with retriggering option
- Complementary Q and Q-bar outputs
- External reset capability
- Oscillator output at 2x frequency available
- Timing formulas: tA = 4.40 RC, tM = 2.48 RC
- Low quiescent power dissipation
