# NSL-6112 — Advanced Photonix / OSI Optoelectronics

## Description

The NSL-6112 is a CdS photocell (photoresistor / light dependent resistor) with a minimum of 1.3 MOhm dark resistance, packaged in a two-leaded plastic-coated ceramic header. CdS photocells are designed to sense visible light from 400 to 700 nm. Their resistance decreases as the light level increases, with efficiency characteristics similar to the human eye.

## Features

- Passive resistance output
- Ceramic package
- Available in hermetically sealed package
- Available in a wide range of resistance values
