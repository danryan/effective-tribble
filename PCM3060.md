# PCM3060 — Texas Instruments

## Description

The PCM3060 is a low-cost, high-performance, single-chip, 24-bit stereo audio codec with single-ended analog inputs and differential analog outputs. The stereo 24-bit ADC employs a 64-times delta-sigma modulator supporting 16-96 kHz sampling rates. The stereo 24-bit DAC employs a 64- or 128-times delta-sigma modulator supporting 16-192 kHz sampling rates. The PCM3060 supports fully independent operation of the sampling rate and audio interface for the ADC and DAC. Each audio interface supports I2S, left-justified, and right-justified formats with 16/24-bit words. Control is via 3-wire SPI or 2-wire I2C compatible serial interface, or hardware mode.

## Features

- 24-bit delta-sigma ADC and DAC
- ADC/DAC asynchronous operation
- Stereo ADC: THD+N -93 dB, SNR 99 dB, Dynamic Range 99 dB (typical, 48 kHz)
- Stereo DAC: THD+N -94 dB, SNR 105 dB, Dynamic Range 104 dB (typical, differential, 48 kHz)
- Sampling rate: ADC 16-96 kHz, DAC 16-192 kHz
- System clock: 128, 192, 256, 384, 512, 768 fS
- Differential voltage output: 8 Vp-p; Single-ended: 4 Vp-p
- Full-scale input: 3 Vp-p
- Antialiasing and analog low-pass filters included
- ADC digital filter: pass-band ripple +/-0.05 dB, stop-band attenuation -65 dB
- DAC digital filter: pass-band ripple +/-0.04 dB, stop-band attenuation -50 dB
- Flexible mode control: 3-wire SPI, 2-wire I2C compatible, or hardware control
- Digital attenuation, soft mute, de-emphasis
- ADC/DAC independent power down
- Dual power supplies: 5V analog, 3.3V digital
- Package: TSSOP-28

## Typical Application Circuits

The typical application uses VCC (5V) for analog supply with 0.1 uF + 10 uF bypass capacitors, VDD (3.3V) for digital supply with similar bypassing, and VCOM output with 0.1 uF + 10 uF bypass. Analog inputs are AC-coupled via 4.7 uF electrolytic capacitors (3 Hz cutoff). Differential analog outputs feed a post low-pass filter and buffer stage. The MODE pin is configured with appropriate tie or pull resistor to select SPI, I2C, or hardware control mode (220 kOhm +/-5% resistor required for pull-up/pull-down modes).
