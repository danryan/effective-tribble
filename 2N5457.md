# 2N5457 — onsemi (ON Semiconductor)

## Description

The 2N5457 is an N-channel junction field effect transistor (JFET), depletion mode (Type A), designed for audio and switching applications. Drain and source are interchangeable. The device features high AC input impedance, high DC input resistance, low transfer and input capacitance, and low cross-modulation and intermodulation distortion.

## Features

- N-channel for higher gain
- Drain and source interchangeable
- High AC input impedance
- High DC input resistance
- Low transfer and input capacitance
- Low cross-modulation and intermodulation distortion
- Plastic encapsulated package (TO-92)
- Pb-free packages available
