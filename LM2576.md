# LM2576 — Texas Instruments

## Description

The LM2576 is a step-down (buck) switching voltage regulator capable of driving a 3 A load with excellent line and load regulation. It is available in fixed output voltages of 3.3 V, 5 V, 12 V, 15 V, and an adjustable output version. The device requires only four external components: an input capacitor, output capacitor, inductor, and catch diode. The fixed-frequency oscillator (52 kHz) simplifies design of the external filter components.

## Features

- 3.3 V, 5 V, 12 V, 15 V, and adjustable output versions
- Adjustable version output range: 1.23 V to 37 V (+/-4% max over line and load conditions)
- Guaranteed 3 A output load current
- Wide input voltage range: 40 V max (60 V for HV version)
- 52 kHz fixed-frequency internal oscillator
- TTL shutdown capability with low standby current
- High efficiency up to 88%
- Uses readily available standard inductors
- Thermal shutdown and current limit protection
- Available in TO-220 and D2PAK packages

## Typical Application Circuits

### Fixed Output Buck Converter

A basic buck converter using the LM2576 with VIN on pin 1, output switch (pin 2) connected through an inductor (L1) to the output. A Schottky catch diode (1N5822 or equivalent) connects from the switch node to ground. Input capacitor (100 uF electrolytic) on pin 1 to ground. Output capacitor (1000 uF electrolytic) from output to ground. Pin 4 (FB) connects to the output. Pin 5 (ON/OFF) tied to ground for always-on operation. The output voltage is set by the fixed internal reference.

### Adjustable Output Buck Converter

Same as the fixed output circuit, but pin 4 (FB) connects to the midpoint of a resistor divider from the output to ground. VOUT = 1.23 V x (1 + R2/R1), where R1 connects from the FB pin to ground and R2 connects from the output to the FB pin.
