# PDV-P9001 — Advanced Photonix

## Description

The PDV-P9001 is a CdS photocell (photoresistor / light dependent resistor) with a minimum of 0.3 MOhm dark resistance, packaged in a two-leaded plastic-coated ceramic header. CdS photocells are designed for visible light measurement to sense light from 400 to 700 nm. Their resistance decreases as the light level increases, with efficiency characteristics similar to the human eye.

## Features

- Passive resistance output
- Ceramic package
- Available in hermetically sealed package
- Available in a wide range of resistance values
