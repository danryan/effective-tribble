# DHO800 -- RIGOL

## Description

The DHO800 series is RIGOL's high-performance economical digital oscilloscope. Though compact in design, it has superior performance featuring a capture rate up to 1,000,000 wfms/s (in UltraAcquire Mode), 25 Mpts memory depth, 12-bit resolution, and low noise. It is designed for embedded design, electronics maintenance, and basic R&D applications.

## Features

- Ultra-low noise floor, purer signal, never miss the small signals
- Up to 12 bits resolution for all models of this series
- Max. analog bandwidth of 100 MHz, 4 analog channels, external trigger output (std.) available for the dual-channel model
- Max. real-time sample rate of 1.25 GSa/s
- Max. memory depth of 25 Mpts
- Vertical sensitivity range: 500 uV/div to 10 V/div
- Max. capture rate of 1,000,000 wfms/s (in UltraAcquire mode)
- Digital phosphor display with real-time 256-level intensity grading
- Waveform search and navigation function
- 7" (1024x600) capacitive multi-touch screen
- USB Device & Host, LAN, and HDMI interfaces (std.) for all models
- Unique online upgrade
- Type-C interface provides power with mobile power supply
