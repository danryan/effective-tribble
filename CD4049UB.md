# CD4049UB — Texas Instruments

## Description

The CD4049UB is a CMOS hex inverting buffer/converter. It features six independent inverting buffer circuits capable of converting high-level logic inputs to low-level logic outputs while providing high current sink and source capability. The CD4049UB can be used for logic-level conversion from CMOS to TTL, driving high-capacitance loads, and LED driving. The "UB" designation indicates unbuffered outputs, providing linear transfer characteristics suitable for analog applications such as oscillators and amplifiers.

## Features

- Six inverting buffers in a single 16-pin package
- Wide supply voltage range: 3 V to 18 V
- High current sink and source capability for driving TTL
- Unbuffered outputs for linear applications
- Logic-level conversion from high-voltage CMOS to low-voltage TTL
- High noise immunity
- Low quiescent power dissipation
- Output drive: IOL up to 6.4 mA, IOH up to -1 mA at VDD = 5 V
- Can accept input voltages greater than VDD

## Typical Application Circuits

### LED Driver

Each inverter output can directly drive an LED with a current-limiting resistor. With VDD = 5 V and a series resistor, the output sinks current through the LED when the input is high (output goes low), or sources current when the input is low (output goes high). The high output drive current capability makes this device suitable for directly driving LEDs without additional buffering.
